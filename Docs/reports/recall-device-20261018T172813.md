# 真机本地召回（10.1：5,000 子块；20,000 子块规模检查）

- 设备：iPhone 15 Pro Max，iOS 27.0.1（24A446）；Xcode 27.1；应用内记录：iPhone16,2 iOS 27.0.1；提交：0676855；Release 构建
- 方法：每个规模在独立 SQLite 文件中写入合成子块（约 300 字/子块、4 子块/父块，与默认切块上限 320/1200 一致）、FTS5 全文索引与 1024 维向量（`text-embedding-v4` 默认维度），用正式 `HybridRetriever`（词法 BM25 + 向量 + RRF + 父块扩展，无重排）在全书范围检索；查询向量由本地哈希生成，**不含网络 Embedding/Rerank**。首个查询包含从 SQLite 读取并解码全部向量（冷读索引），单独列出；之后 30 次为热查询。临时库在测完后删除。

- 5,000 子块：每次查询返回 5～8 个结果单元（冷查询 7 个），确认检索确实命中。
- 20,000 子块：每次查询返回 7～8 个结果单元（冷查询 8 个），确认检索确实命中。
- 5,000 子块：检查点前 WAL 4.7 MB，检查点后 0.0 MB。
- 20,000 子块：检查点前 WAL 4.7 MB，检查点后 0.0 MB。
- 内存为进程 phys_footprint；索引体积为 WAL 检查点（TRUNCATE）后的 SQLite 主库文件大小，包含子块与父块正文、FTS5 索引与 1024 维向量。
